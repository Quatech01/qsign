Qsign API Reference

Multi-tenant GPS attendance API. All endpoints are prefixed with /api. Protected routes require a JWT via Authorization: Bearer <token>.

Base URLhttps://qsign.uk/api
Auth headerAuthorization: Bearer <token>
Content-Typeapplication/json
Token lifetime8 hours (JWT, HS256)
Authentication
POST/auth/login Public▼
Authenticate a worker or admin. Returns a signed JWT and basic user info.
Request body
{
  "company_code": "ACME01",
  "email":        "alice@acme.com",  // or staff_id
  "staff_id":     "EMP-42",          // alternative
  "password":     "••••••••"
}
Response 200
{
  "token": "eyJhbGci...",
  "user": {
    "id":         7,
    "name":       "Alice",
    "email":      "alice@acme.com",
    "role":       "worker",
    "department": "Engineering",
    "staff_id":   "EMP-42"
  },
  "company": {
    "name":         "Acme Ltd",
    "company_code": "ACME01"
  }
}
GET/auth/me Any role▼
Verify a token and return the caller's profile. Use on app load to confirm the session is still valid.
Request
No body. Token required in header.
Response 200
{
  "id":         7,
  "name":       "Alice",
  "email":      "alice@acme.com",
  "role":       "worker",
  "department": "Engineering",
  "phone":      "+44 7700 900123",
  "staff_id":   "EMP-42"
}
Attendance — Worker endpoints
POST/attendance/checkin Worker▼
Clock in. Validates GPS coordinates against the worker's assigned geofence. Returns 403 if outside radius.
Request body
{
  "lat": 51.5074,
  "lng": -0.1278
}
Response 200
{
  "message":      "Checked in successfully",
  "locationName": "Head Office, London",
  "record": {
    "id":             201,
    "user_id":        7,
    "location_id":    3,
    "check_in_time":  "2026-08-31T08:47:00Z",
    "check_out_time": null,
    "check_in_lat":   51.5074,
    "check_in_lng":   -0.1278,
    "hours_worked":   null
  }
}
403 returned when coordinates fall outside the geofence radius.
POST/attendance/checkout Worker▼
Clock out of the current open session. Server calculates and stores hours_worked.
Request body
{
  "lat": 51.5074,
  "lng": -0.1278
}
Response 200
{
  "message":     "Checked out successfully",
  "hoursWorked": 7.83,
  "record": {
    "id":             201,
    "check_out_time": "2026-08-31T16:37:00Z",
    "check_out_lat":  51.5074,
    "check_out_lng":  -0.1278,
    "hours_worked":   7.83
  }
}
GET/attendance/status Worker▼
Check whether the current worker is clocked in. Returns the open record if yes.
Request
No body.
Response 200
{
  "clocked_in": true,
  "record": {
    "id":            201,
    "check_in_time": "2026-08-31T08:47:00Z",
    "location_name": "Head Office"
  }
}
// or:
{ "clocked_in": false, "record": null }
GET/attendance/today Worker▼
All sessions for today with total hours accumulated.
Request
No body.
Response 200
{
  "totalHours": 7.83,
  "records": [{
    "id":             201,
    "check_in_time":  "2026-08-31T08:47:00Z",
    "check_out_time": "2026-08-31T16:37:00Z",
    "hours_worked":   7.83,
    "location_name":  "Head Office"

Admin — Workers
GET/admin/workers Admin▼
All workers with payroll and compliance fields pre-computed.
Response 200 — array
[{
  "id":                  7,
  "name":                "Alice",
  "email":               "alice@acme.com",
  "staff_id":            "EMP-42",
  "role":                "worker",
  "department":          "Engineering",
  "phone":               "+44 7700 900123",
  "active":              true,
  "location_id":         3,
  "location_name":       "Head Office",
  "weekly_hours":        40.00,     // target Mon–Sun
  "week_hours_worked":   27.50,     // actual this week
  "pay_rate":            12.50,     // £/hr
  "pay_period":          "monthly", // company setting
  "period_hours_worked": 62.00,     // hours in pay window
  "period_pay":          775.00     // period_hours × pay_rate
}]
POST/admin/workers Admin▼
Create a new worker. Fields marked * are required.
Request body
{
  "name":         "Bob Jones",    // *
  "email":        "bob@acme.com", // *
  "password":     "••••••••",     // *
  "staff_id":     "EMP-43",
  "role":         "worker",
  "department":   "Ops",
  "phone":        "+44 7700 900000",
  "location_id":  3,
  "weekly_hours": 40,
  "pay_rate":     12.50
}
Response 201
{
  "id":           8,
  "name":         "Bob Jones",
  "email":        "bob@acme.com",
  "staff_id":     "EMP-43",
  "role":         "worker",
  "active":       true,
  "weekly_hours": 40.00,
  "pay_rate":     12.50
}
PUT/admin/workers/:id Admin▼
Update any worker fields. All optional — omitted fields keep existing values (COALESCE).
Request body (all optional)
{
  "name":         "Bob Smith",
  "email":        "bob2@acme.com",
  "password":     "newpass",
  "staff_id":     "EMP-43",
  "role":         "admin",
  "department":   "Ops",
  "phone":        "+44 7700 900001",
  "active":       false,
  "location_id":  4,
  "weekly_hours": 37.5,
  "pay_rate":     14.00
}
Response 200
{ ...updated worker object }
DELETE/admin/workers/:id Admin▼
Permanently delete a worker. Attendance records are cascade-deleted.
Request
No body.
Response 200
{ "message": "Worker deleted" }
// 404 if not found

Manually correct a record. Audit reason required — stored with admin ID and timestamp.
Request body
{
  "check_in_time":  "2026-08-31T09:00:00Z", // *
  "check_out_time": "2026-08-31T17:00:00Z",
  "edit_reason":    "Clock missed at gate",   // *
  "notes":          "Confirmed by supervisor"
}
Response 200
{ ...updated record }

Setup — SETUP_KEY protected
POST/companies/register SETUP_KEY▼
Bootstrap a new company with its first admin. Returns a login token immediately.
Request body
{
  "company_name": "Acme Ltd",
  "company_code": "ACME01",
  "admin_name":   "Jane Admin",
  "admin_email":  "jane@acme.com",
  "password":     "securepass",
  "setup_key":    "<SETUP_KEY>"
}
Response 201
{
  "message": "Company registered",
  "token":   "eyJhbGci...",
  "company": { "id": 2, "name": "Acme Ltd" },
  "user": { "id": 9, "role": "admin" }
}
POST/companies/list SETUP_KEY▼
List all registered companies with admin details.
Request body
{ "setup_key": "<SETUP_KEY>" }
Response 200
[{
  "id":           1,
  "name":         "Acme Ltd",
  "company_code": "ACME01",
  "admin_email":  "jane@acme.com"
}]
POST/admin-reset SETUP_KEY▼
Reset the password of all admins for a company. Emergency recovery only.
Request body
{
  "setup_key":    "<SETUP_KEY>",
  "company_code": "ACME01",
  "new_password": "newpass"
}
Response 200
{
  "message": "Password reset for 1 admin(s)",
  "admins":  [{ "id": 9, "email": "jane@acme.com" }]
}
